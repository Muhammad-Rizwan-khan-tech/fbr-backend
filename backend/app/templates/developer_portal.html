API Authentication & Headers

Every request to the Developer API must include your cryptographically hashed API Key in the X-API-Key request header.

Webhook Signature Verification (HMAC-SHA256)

When an invoice is validated or rejected by the FBR gateway, our worker pushes an asynchronous HTTP POST to your registered webhook URL. Each payload is cryptographically signed using your secret key (whsec_...).

Incoming Request Headers:

X-FBR-Signature: sha256=4f53cdae6...
X-FBR-Timestamp: 1791515291

Python Verification Example:

import hmac
import hashlib
import time

def verify_fbr_webhook(raw_payload_bytes: bytes, signature_header: str, timestamp_header: str, secret: str) -> bool:
    # 1. Prevent replay attacks: ensure timestamp is within 300 seconds (5 min)
    if abs(time.time() - int(timestamp_header)) > 300:
        return False

    # 2. Recompute expected HMAC-SHA256
    signed_payload = f"{timestamp_header}.".encode("utf-8") + raw_payload_bytes
    expected_sig = hmac.new(secret.encode("utf-8"), signed_payload, hashlib.sha256).hexdigest()

    # 3. Constant-time comparison
    received_sig = signature_header.replace("sha256=", "")
    return hmac.compare_digest(expected_sig, received_sig)
